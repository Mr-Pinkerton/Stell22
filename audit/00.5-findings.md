## SEC-001 — Admin mutations без авторизации в теле action

| | |
| --- | --- |
| **Severity** | **P0** |
| **Type** | Missing authorization (systemic) |
| **Affected** | **108** из 125 exports без `requireAdmin` / `requireTerminalEmployee` (кроме auth-flow) |
| **Exploitable now** | **46 writes** с terminal worker — без любой cookie |

**Evidence:**

- `src/server/session.ts` L39–44 — layout не защищает POST
- `requireAdmin` только: `settings.ts` (6), `marketplace.syncMarketplaces` (1)
- `src/proxy.ts` L8, L19–21 — `/terminal` public
- `.next/server/server-reference-manifest.json` — **78** actions, worker `app/terminal/page`
- Пример: `finance.createCashFlow` — no auth, tw=yes (`finance.ts` L809)

**Impact:** создание/удаление проводок, импорт выписок, выплата ЗП (`markEmployeePaid`), CRUD партий, пересчёт себестоимости, freeze batch costs.

**Fix direction:** `requireAdmin()` в начале каждой admin mutation/read (или split modules: admin-only без импорта в terminal graph); отдельный terminal API surface.

**Not split per-action** — одна systemic finding.

## SEC-002 — `loadStoredApiCredentials` возвращает секреты без auth

| | |
| --- | --- |
| **Severity** | **P0** |
| **Type** | Sensitive data disclosure |
| **File** | `src/server/settings.ts` L53–64 |

**Evidence:**

- Export в `"use server"` файле, **без** `requireAdmin`
- Prod manifest: **yes**, terminal worker: **yes**
- Читает `Setting` where `key startsWith apiCred:` → plaintext values
- `getApiCredentials` (L70) вызывает `requireAdmin`, но **не** блокирует прямой вызов sibling export

**Impact:** утечка Ozon/WB API keys → внешние маркетплейсы, финансовые данные МП.

**Fix direction:** убрать из `"use server"`; internal function в server-only module; единственный export с keys — `getApiCredentials`.

## SEC-003 — `getTerminalData` на публичном `/terminal`

| | |
| --- | --- |
| **Severity** | **P1** |
| **Type** | Excessive data exposure (read) |
| **Files** | `terminal.ts` L187–232; `app/terminal/page.tsx`; `terminal-app.tsx` |

**Evidence:**

- No auth; RSC loads on first paint
- Returns: employee rates, birthDate, batch purchase costs, full stock, BOM
- PIN stripped (`serEmployee` L80–81)

**Impact:** коммерческая тайна (себестоимость, ставки), персональные данные (ФИО, дата рождения). Write-path terminal (`submit*`) защищён отдельно.

**Fix direction:** minimal terminal DTO after PIN login; или require terminal session even for read snapshot.

## SEC-004 — Admin-only worker mutations без in-action check

| | |
| --- | --- |
| **Severity** | **P2** |
| **Type** | Defense in depth failure |
| **Affected** | **31 writes** без terminal worker (employees, nomenclature, warehouse, production, …) |

**Evidence:**

- `employees.createEmployee` — tw=no, auth=— (`employees.ts` L104)
- Proxy blocks unauthenticated POST to `/employees`
- **With valid admin JWT** (proxy only checks signature): action runs without `requireAdmin`

**Impact:** любой обладатель session cookie (XSS, physical access, leaked cookie) — full admin write surface.

**Fix direction:** same as SEC-001 — `requireAdmin()` everywhere.

## SEC-005 — `syncMarketplacesAsUser(userId)` без проверки

| | |
| --- | --- |
| **Severity** | **P2** |
| **Type** | Missing authorization |
| **File** | `marketplace.ts` L504 |

**Evidence:**

- Public `"use server"` export; no `requireAdmin`
- Workers: `app/(admin)/sales/page`, `app/(admin)/warehouse/page` only (**no** terminal worker)
- `syncMarketplaces` wrapper calls `requireAdmin` then delegates

**Impact:** при admin session — sync от произвольного `userId` в audit logs; HTTP calls to MP with stored keys.

## Max blast radius (unauthenticated)

```text
Attacker → POST https://host/terminal (no cookies)
         → Server Action: importStatement / createCashFlow / markEmployeePaid
         → deleteBatch / recalcBatchCosts / loadStoredApiCredentials
```

**Result:** финансы и склад перезаписаны; ЗП помечена выплаченной; себестоимость пересчитана; API keys утекли; audit ChangeLog без userId или с forged context.

---

## Remediation sequence (для следующих этапов, не делать сейчас)

1. **P0 hotfix:** `requireAdmin()` helper в **каждой** admin read/write (finance, payroll, purchases, cost, goals, notifications reads, …).
2. **P0:** `loadStoredApiCredentials` → server-only module; remove from manifest surface.
3. **P1:** split terminal DTO / auth-gated `getTerminalData`.
4. **P1:** reduce shared server graph so finance actions **not** on terminal worker (или gate `/terminal` actions server-side globally).
5. **P3:** move `reverse*` out of `"use server"`; add role check to proxy when multi-role appears.
