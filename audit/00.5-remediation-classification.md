# Этап 0.5: целевая классификация Server Actions

Сгенерировано из единственного machine-readable источника:
`scripts/security/server-action-policy.mjs`.

Классификация относится к **125 экспортам до remediation**. После переноса
`INTERNAL_SERVER` ожидается 111 публичных Server Actions.

| Категория | Количество | Инвариант |
| --------- | ---------- | --------- |
| `ADMIN_ACTION` | **101** | Client-callable admin read/write; requires `requireAdmin()` first. |
| `TERMINAL_ACTION` | **6** | Post-PIN terminal endpoint; requires terminal session. |
| `AUTH_ACTION` | **4** | Session establishment/teardown. |
| `PUBLIC_INTENTIONAL` | **0** | Deliberately anonymous Server Action. |
| `INTERNAL_SERVER` | **14** | Server-to-server helper; must not be in the action manifest. |
