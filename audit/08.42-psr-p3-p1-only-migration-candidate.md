The wrapper does not build, start, or replace an application container. A second call, when P1 is already applied, does not spawn.

None of those results set `executionAuthorized`. The public CLI still returns `LIVE_DISPOSABLE_PROBE_NOT_IMPLEMENTED`. `allowProduction` stays false.

`.github/workflows/p1-only-migration.yml` is manual and has no production environment. Its gate exits 2 with `BACKUP_CHECKSUM_REQUIRED`. It was not dispatched.

`deploy-production.yml` now checks out the deploy SHA and runs `scripts/assert-production-deploy-separation.mjs` before the SSH step.
