## 1. What this candidate is

The code under `src/server/internal/p1-isolated-runner/` builds a private migration directory from the pinned Git blobs, classifies Prisma history and P1 catalog evidence, and can spawn `prisma migrate deploy` only after a disposable PostgreSQL 17 attestation matches a nonce stored in that database.

The CLI entry `scripts/p1-isolated-runner.ts` plans by default. Its apply path validates an attestation file and then stops with `LIVE_DISPOSABLE_PROBE_NOT_IMPLEMENTED`. It does not open a socket and it does not spawn Prisma.

There is no production flag, force flag, bypass flag, `migrate resolve` path, SQL replay, or retry after an ambiguous spawn.

## 2. Verdicts

| Verdict | Meaning in this candidate |
| --- | --- |
| `READY_FOR_DISPOSABLE_APPLY` | Forty-five historical rows match the pinned checksums and are finished. P1 has no history row. The P1 column, check, function, and trigger are absent. |
| `ALREADY_APPLIED` | P1's finished row matches the pinned checksum and the catalog definitions match the contract. A repeat call does not spawn Prisma. |
| `STOP` | Inventory, checksum, identity, or object-definition mismatch. Also a non-zero Prisma exit. No retry. |
| `BLOCKED` | Failed, rolled-back, unfinished, partial, or ambiguous bookkeeping; host-lock contention; ambiguous process completion. No automatic recovery. |

Schema classification reads definition text (`pg_get_constraintdef`, `convalidated`, `pg_get_functiondef`, `prosecdef`, `pg_get_triggerdef`, `tgenabled`). It does not treat a process exit code as schema state. Those SQL texts are not executed by this candidate.

## 3. Disposable boundary

A target is rejected unless all of the following match: UUID run id, database name `p1disp_<run id>`, loopback host, user `p1disp`, 64-character container id, service name tied to that run, image `postgres:17` or `postgres:17-alpine`, major version 17, and a nonce of at least 32 characters that the probe reads back from the database.

Rejected names include `stell22`, `stell22_integrity`, and `stell22_dev`. Rejected container names include `stell22-db-prod`, `stell22-app`, and `stell22-caddy`. Host `db` is rejected. Localhost without the rest of the attestation is rejected.

Inherited `DATABASE_URL`, `INTEGRITY_TEST_DATABASE_URL`, `PROD_*`, and `POSTGRES_*` values are removed from the child environment. The child receives a URL built from the attestation only. The parent environment is left unchanged.

The host lock is an exclusive file create. This candidate does not take Prisma's session advisory lock. A stale lock is not deleted. The gap between the last hash check and the child start is not claimed to be atomic.
