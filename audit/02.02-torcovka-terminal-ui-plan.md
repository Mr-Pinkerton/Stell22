# Этап 02.02: TORCOVKA terminal UI — implementation plan

> **For agentic workers:** do not implement until the owner says implement after reviewing this plan and `audit/02.01-torcovka-terminal-ui-review.md`. This is UI-only. When implementing: stay inside STEP 1→2→3. Do not start schema, server, or draft-persistence work.

**Goal:** Make the TORCOVKA terminal screen match the owner reference **structure** (selected batch → lot cards → sort/length grid → 3-metric sticky summary) while keeping Stell22 visual language and **all current TORCOVKA business logic**.

**Architecture:** Keep all state, draft autosave, `clientRequestId`, submit/ack/approval, and dialog ownership in `TorcovkaScreen`. Change markup/CSS first. Extract presentational children only if STEP 1 markup is too large. Shared terminal primitives (`QuantityDialog`, `NumericKeypad`, `TerminalHeader`, `TerminalDraftResumeDialog`) stay on their current contracts. `TerminalConfirmBar` may gain an optional `className` so TORCOVKA can pin the bar; default sticky behavior for PRISADKA/UPAKOVKA stays.

**Tech Stack:** existing Next.js client components, Tailwind tokens (`surface-card`, `brand`, Montserrat), Lucide, `formatLength`, `computeTorcovkaWasteMetrics`. No new design-system kit. No Zod. No Prisma.

**HEAD this plan assumes:** `4809c0cfdce11ada8563d6c6d8cb7f7069c90c85`

**Evidence:** `audit/02.01-torcovka-terminal-ui-review.md`. Visual structure from owner reference (2026-09-06). Palette of the mock is **not** a spec.

## 3. Lot card content

Only fields already on `TerminalRailLot` + local `railsTaken` + `lotId`.

```text
[icon Layers]
Title:   Пакет {code}   |  Поштучно
Line 2:  {Полка|Канавка} · {1 сорт|2 сорт пакета} · {formatLength(lengthM)}
Unselected:  Осталось {remainingQuantity} шт
Selected:    Взято {railsTaken} / {remainingQuantity} шт
             thin progress: railsTaken / remainingQuantity
Selected chrome: border-brand border-2 bg-brand/5  (not mock blue)
```

Do **not** show: исходный `quantity`, порода, сечение (они на карточке партии), batch name, цены, waste.

Tap target: whole card ≥ 56 px height; prefer `min-h-36` / keep ~`h-40`. No nested tiny controls except the existing flow (tap opens QuantityDialog).

## 4. Blank entry UX

Fastest factory path **without** changing the data model:

1. Sort tab (if needed) — 1 tap.
2. Length card — 1 tap → QuantityDialog (keypad, already ≥56 px).
3. Подтвердить in dialog — 1 tap.
4. Repeat. Same length again: tap card, dialog opens with `initial` qty.
5. Delete: «Сбросить» on the card, hit area `min-h-14 min-w-14` (not a text link).

Do not add +/- steppers that bypass `maxDetailQuantity`. Do not type lengths. Do not merge SORT1/SORT2 into one grid.

Card content:

```text
qty badge (tabular-nums) top-right     0 is allowed visually; active chrome if qty > 0
title: formatLength(lengthM)
subtitle: SORT_LABEL[activeSort]
```

`OperationTileGrid` may stay `grid-cols-5` on wide landscape. Below a comfortable width (`max-lg` or similar) `grid-cols-3` is acceptable. Do not build a phone layout.

## 5. Sticky / pinned summary

Pinned to the bottom of the TORCOVKA screen. Show when `lot` is selected **or** on today’s lotMissing draft fallback (`lotMissing && railsTaken > 0 && pickedCount > 0`). If `railsTaken === 0`, still show the bar with нули (`formatLength(0)`, `pickedCount` шт) so Confirm stays on-screen; the button stays disabled. Do not show the bar on a fresh screen with no lot.

| Label | Value | Unit | Source |
| --- | --- | --- | --- |
| Заготовок | `pickedCount` | шт | sum of `picked` |
| Использовано | `wasteMetrics.takenM` | м | `formatLength` |
| Отход | `wasteMetrics.wasteM` | м | `formatLength`; secondary `{canon.wastePct}` % with comma |

Band on Отход only:

| Band | Class (existing intent) |
| --- | --- |
| NORMAL | `text-muted-foreground` |
| SUSPICIOUS | `text-amber-700 font-medium` |
| EXTREME | `text-destructive font-semibold` |

If `wasteMetrics` is null (lot missing): keep today’s draft fallback text in the summary slot, still with the Confirm button disabled/enabled by the same flags.

Disabled rule **unchanged**:

```ts
disabled={railsTaken <= 0 || pickedCount === 0 || overLength || submitting}
```

## 11. STEP 1 markup notes (implementer)

`TerminalConfirmBar` today:

```20:21:src/components/terminal/terminal-confirm-bar.tsx
    <div className="surface-card sticky bottom-4 mt-auto flex items-center justify-between gap-4 px-5 py-3 ring-0">
```

Allowed minimal change:

```tsx
interface TerminalConfirmBarProps {
  summary: React.ReactNode;
  disabled?: boolean;
  onConfirm: () => void;
  label?: string;
  className?: string;
}

<div className={cn(
  "surface-card sticky bottom-4 mt-auto flex items-center justify-between gap-4 px-5 py-3 ring-0",
  className,
)}>
```

TORCOVKA usage: `className="static mt-0"` so the parent pin owns placement. PRISADKA/UPAKOVKA omit `className` and keep `sticky bottom-4`.

Summary children (calculations already in `TorcovkaScreen`):

```tsx
<div className="flex flex-wrap items-center gap-6">
  <Metric label="Заготовок" value={`${pickedCount} шт`} />
  <Metric label="Использовано" value={formatLength(wasteMetrics.takenM.toNumber())} />
  <Metric
    label="Отход"
    value={`${formatLength(wasteMetrics.wasteM.toNumber())}`}
    hint={`${wasteMetrics.canon.wastePct.replace(".", ",")}%`}
    className={wasteBandClass(wasteMetrics.band)}
  />
</div>
```

Do not use `toFixed` on meters for display — `formatLength` is the Stell22 formatter.

Lot progress (presentation only):

```tsx
const ratio =
  lot.remainingQuantity > 0
    ? Math.min(1, Math.max(0, railsTaken / lot.remainingQuantity))
    : 0;
```

If `stockLow` (`railsTaken > remainingQuantity`), still show the warning; do not invent a second blocking state.
