# 09.18 Settings and goals — phase 08

**Database:** `p1iso_f5f4bb7f`. No production settings were read. The fake API token is not copied into this file.

## Goals

`createGoal` (`src/server/goals.ts:85–91`) accepts any quantity above zero and then stores `Math.round`. A request of `0.4` returned `ok: true` and stored `0`. A second goal of `10` for the same product was also stored. There is no unique key on product plus month.

`getGoalsData` counts non-cancelled упаковка by `productId` and `formatGoalMonthIso(workDate)`. Both goals showed produced `2`, which is the edited pack. The goal of `0` therefore has a fact and a zero target. `goalCompletionPercent` returns `0` when the target is not positive. `BA-P08-002`.

`formatGoalMonthIso` uses the host calendar (`goals.ts:64–67`). The instant `2026-10-31T21:30:00Z` is 00:30 on 1 November in UTC+3. Under `TZ=UTC` the same getter returns `2026-10`. Under `TZ=Europe/Moscow` it returns `2026-11`. Report periods were deliberately moved off the host clock (`dates.ts:100–104`). Goals were not. On this Windows host the pack fell in November, so the disposable row is not the wrong month. A UTC process would place that pack in October. `BA-P08-007`.

The dashboard plan adds the quantities of every active goal of the month (`dashboard-metrics.ts:119–122`). Two goals on one product add both targets while each goal shows the full pack count. Whether two goals per product-month are allowed is `BA-P08-008`. No separate weekly or daily goal writer exists. The forecast in `buildGoalProgress` is `(produced / day) × days in month`.

## Minimum stock

`saveMinStock` (`settings.ts:195`) keeps `Math.round(n)` when `n > 0`. `0.4` is positive, rounds to `0`, and is stored as `0`, not `null`. The comment on the function says `0` means the signal is off. The column now holds `0`. `BA-P08-003`.

A later save of `5` on the product left product stock at `2`. `getDashboardData` still returned no low-stock name. The alert reads only `NomenclatureItem.minStock` against `NomenclatureStock` (`dashboard.ts:89–93`). After a fastener minimum of `5` with stock `0`, the alert name was «P08 screw». Product and detail minima are edited in «Минимальные остатки на складе» and do not reach that alert. `BA-P08-004`.

A save that named a missing product threw inside the transaction. The product minimum stayed `5`. The batch is atomic.
