## 6. Replay / gate

- Same `requestId` + exact payload: return retained command. No physical mutation. No InventoryMovement. No ChangeLog.
- OFF → later ON replay: no backfill.
- ON → later OFF replay: no duplicate.
- Same `requestId` + different payload or admin: `REQUEST_ID_REUSE`.
- Missing / INACTIVE gate: physical mutation + retained command; InventoryMovement = 0.
- ACTIVE gate: physical mutation + retained command + SHADOW movements atomically.
- Malformed `inventory_movement_shadow_write`: global fail-closed, including replay.
- Gate ON/OFF control takes EXCLUSIVE (8322,1). A writer that started OFF/ON commits completely as OFF/ON.
