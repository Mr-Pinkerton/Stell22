## 2. What the main image does

`Dockerfile` now ends with `ENTRYPOINT ["./docker-entrypoint-app-only.sh"]`. The runner stage copies the Next.js build, `node_modules`, `prisma`, `src`, `tsconfig.json`, and the app-only script. It does not copy `docker-entrypoint.sh`. There is no bypass flag and no fallback to that script.

Normal startup is the existing gate, unchanged:

1. Configuration must include `DATABASE_URL` and `SESSION_SECRET`.
2. The login is refused when it is a superuser, owns the schema or database, belongs to another role, or can create objects.
3. Migration history must already match the image inventory. A missing, pending, or failed migration is refused.
4. Next.js starts only after that gate returns success.

The gate's SQL remains read-only. This package does not rewrite `src/server/internal/p1-app-only-startup/gate.ts`, `run.ts`, `probe.ts`, or `inventory.ts`.
