## 5. Failure and rollback limits

The ownership script is one transaction. A refused plan applies no SQL. A statement error inside that transaction rolls the transaction back. After it commits, a later P1 or application failure does not undo the ownership transfer. Removing the disposable database is not a production rollback. An application restart does not roll the schema back. This rehearsal does not restore a backup over the database it migrated.
