# HEAD bootstrap

Canonical global HEAD governance is pinned in this repository as a Git submodule:

`.head/global-governance/GLOBAL_HEAD_GOVERNANCE.md`

Before substantial HEAD work:

1. Verify that `.head/global-governance` is initialized at the pinned commit.
2. Read the complete `GLOBAL_HEAD_GOVERNANCE.md`.
3. Read this repository's project-specific governing documentation, including `AGENTS.md` and applicable `.cursor/rules/**`.
4. Apply both global and project-specific governance. If they conflict, follow the stricter project-specific rule.

Do not substitute the moving `main` branch of `head-governance` for this repository's pinned submodule commit.
